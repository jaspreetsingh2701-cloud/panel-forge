# PanelForge Web

Next.js application for the PanelForge builder, preview experience and published application runtime.

## Local development

From the repository root:

```bash
pnpm --filter @panelforge/web dev
```

Open [http://localhost:3000](http://localhost:3000).

## Current scope

The initial page is a product-shell placeholder. Builder functionality, authentication, API integration and published-app rendering will be implemented in later batches.
