# Design Changelog

All notable changes to the PanelForge product design are recorded here.

## 2026-11-12 — Initial approved UX baseline

**Status:** Approved during product design review; repository documentation is being added separately.

### Added
- Dark-first visual direction with user-selectable light theme.
- Refined existing PanelForge brand and landing-page content.
- Premium glassmorphism direction with restrained purple/cyan accents.
- Shared sidebar/dashboard hierarchy.
- Theme toggle in public and authenticated headers.
- Shared component foundations and accessibility requirements.
- Theme lifecycle: browser preference before login, profile preference after login, immediate UI update and cross-device synchronization.
- Twelve screen/state specifications.
- Internal /design showcase requirement using real tokens and shared components.

### Not included in this approval
- Frontend route/component implementation.
- Final visual QA of proposed light palette and glass opacity/blur values.
- Password recovery, email verification, invitations, billing, data-source credential workflows or application-publishing backend.
- Any claim that the internal /design route already exists.

Future changes to approved decisions must be recorded in UX_DECISIONS.md and reflected in affected specifications.
